# AI Nakama（AI仲間Mod）

マイクラ Java版 26.3（Fabric）に、言葉で指示できる村人の仲間を追加するModです。
AIは「何をどの順でやるか」の計画だけを立て、歩く・掘る・クラフト・建築はプログラムが行います。
AIを呼ぶのは話しかけられたときと、プログラムで直せない失敗をしたときだけなので、AIの利用料を低く抑えられます。

## 必要なもの

- Minecraft Java版 26.3
- Fabric Loader 0.19.5 以上、Fabric API
- Ollama（PCで動く無料のAI）と、モデル `qwen3.5:4b`
  - Claude などのAPIを使う場合は Ollama は不要（下の「設定」を参照）

## 遊び方

| やりたいこと | 方法 |
|---|---|
| 仲間を出す | `/nakama spawn` または `/nakama spawn 名前`（チートが有効なワールドで） |
| 話しかける | チャットにそのまま打つ：`小屋を建てて`（1人で遊んでいるときは名前がいらない。最後に話しかけた仲間、いなければいちばん近くの仲間に届く）。相手を選ぶときや、ほかのプレイヤーがいるときは名前から始める：`ミナ、小屋を建てて` `ミナ小屋を建てて` `@ミナ 小屋を建てて`。`みんな` `皆` `全員` で近くの全員 |
| 今の様子を見る | 素手で右クリック |
| 覚えたものを見る・消す | `/nakama skills` / `/nakama forget 名前` |
| AIの使用量を見る | `/nakama usage` |
| 設定の読み直し | `/nakama reload` |

### AIを使わずにすぐ動く言い方

`ついてきて` / `止まって` / `帰って` / `ここを拠点にして` / `拠点はどこ？` / `持ち物は？` / `しまって` / `それを渡して` /
`木を10本集めて` / `石を一スタック掘ってきて` / `松明を8個作って` / `小屋を建てて` / `拠点に柵を作って` / `ここに扉を置いて` /
`チェストから石を10個出して` / `鉄の原石を8個焼いて` / `ガラスを4個作って` / `畑仕事して` / `敵を倒して` / `守って` /
`牛を3頭狩って` / `肉を集めて` / `革を3枚集めて` / `落ちてるものを拾って` / `ここを耕して` / `ここに畑を12マス作って` /
`石のツルハシがほしいな` / `松明を8個用意して` / `羊の毛を刈って` / `乳しぼりして` / `牛を増やして` / `釣りをして` /
`ここを明るくして` / `小麦を売って` / `パンを2個買ってきて` / `村人の取引を見せて` /
`木を2本集めて、松明を4個作って`（いくつか続けてもよい） / `〇〇だから覚えておいて`

「ここ」はプレイヤーが見ているブロックのところ。数は `10` `十` `一スタック` `半スタック` のように言える。
これ以外の言い方は、AIが意味を考えて計画にします。

### 仲間ができること

| 命令 | 内容 |
|---|---|
| follow / stop / move_to | ついていく・止まる・移動する。歩いて行けないときは、そばへ移る |
| collect | 原木・丸石・石炭・鉄の原石・土・砂・砂利・粘土。地表になければ階段状に掘り下げる。道具が要れば先に作る |
| craft | マイクラ本体のクラフトのレシピにあるもの。途中の材料も自動で作る。鉄インゴットのように焼いて作る材料は、自分で焼く |
| smelt | かまどで焼く（鉄インゴット・ガラス・木炭・石・焼いた肉など、本体のかまどのレシピにあるもの）。かまどがなければ作って置き、燃料の原木も自分で集める |
| build | 小屋（5×5、扉つき）・柵（7×7）・覚えた設計図。平らな場所を選び、整地してから建てる。高いところは足場を積む |
| place | ブロックを1つ置く（扉・松明・作業台・チェストなど） |
| give | プレイヤーに渡す |
| store | 道具以外の持ち物を近くのチェストにしまう |
| take | 近くのチェスト（樽も可）から取り出す。数を言わなければ、あるだけ全部 |
| farm | 畑の世話。育ちきった作物（小麦・ニンジン・ジャガイモ・ビートルート）を収穫して植え直し、空いた畑には持っている種を植える |
| fight / guard | 近くの敵（モンスター）を倒す／プレイヤーについていき、近づく敵を倒す。持っている中でいちばん強い剣か斧を使う |
| hunt | 動物（牛・豚・羊・ニワトリ・ウサギ）を狩って、落としたものを拾う。肉・革・羊毛・羽などを名指しで頼んでもよい |
| pickup | 近くに落ちているアイテムを拾う |
| till | 地面を耕して新しい畑にする（クワは自分で作る）。種をまくのは farm |
| get | アイテムを用意する。手に入れ方（チェストから出す・集める・狩る・しぼる・釣る・焼く・クラフト）はプログラムが選ぶ |
| shear / milk / breed | ハサミで羊の毛を刈る / バケツで牛の乳をしぼる / 動物にエサをやって増やす |
| fish | 釣り竿を持って水辺で釣る |
| light | まわりの暗い地面に、間をあけて松明を置く |
| buy / sell | 村人から買う / 村人に売る |
| skill | 覚えた技を使う |
| say / remember | 話す・覚える |

クラフトやかまどの材料が足りないときは、近くのチェストに入っていればそこから出し、なければ集める。

まだできないこと：バケツで水や溶岩を運ぶこと、溶鉱炉・燻製器を使うこと、手に入れ方を教えていないもの（ダイヤモンドなど）を取ってくること。食べる・防具を着ける・寝るは、仲間がダメージを受けず空腹にもならないので入れていません。

### 教えて覚えさせる

| 教え方 | 言い方 | 保存先 |
|---|---|---|
| 建物を見せる | `見てて` → 自分で建てる → `これが見張り台だよ` | `config/ainakama/blueprints/` |
| 手順を言葉で | `キャンプの準備っていうのは、木を3本集めて、作業台を1個作ることだよ` | `config/ainakama/skills.json` |
| 決まり | `夜になったら拠点に帰って`（朝・雨・敵・持ち物がいっぱい・プレイヤーが遠い・暇、も使える） | 同上 |
| 知識 | `鉄は拠点の北の洞窟にあるって覚えておいて` | 仲間ごと（ワールドに保存） |

名前・きっかけ・手順は、できるだけプログラムが直接読み取ります（小さいAIは「教わった」と気づけないことが多いため）。
読み取れない説明だけ、AIに命令へ直してもらいます。覚えた技・決まりは、AIを使わずに実行します。
AIに渡すのは、今回の言葉に関係がありそうな技と知識だけなので、たくさん覚えても送る量は増え続けません。

### 決まりごと

- 仲間はダメージを受けません（`/kill` を除く）
- 掘ったりどけたりするのは自然のもの（土・石・砂・草・葉っぱのついた木）だけ。プレイヤーが置いたらしいブロックは壊しません
- 畑では、育ちきった作物だけを収穫します（育っている途中のものには触りません）
- 中に何か入っているかまど（プレイヤーが使っている途中のもの）には手を出しません
- 戦う相手はモンスターだけ。村人は攻撃しません。エンダーマンやゾンビピグリンは、怒っているときだけ相手にします
- 動物は「狩って」と頼まれたときだけ倒します。名前を付けた動物・リードにつないだ動物・子どもは狩らず、同じ種類の大人が近くに2頭以下になるときも狩りません
- 歩いているだけでは物を拾いません。拾うのは、頼まれたときと、自分で倒した相手が落としたものだけです
- 羊毛は、ハサミを持っていれば刈って取ります（羊を倒しません）
- 道具は、持っている中でいちばん速く掘れるものを使います。たくさん集めるときは、斧・シャベル・石のツルハシを自分で作ります。道具はすり減りません
- 手の届かない高さの原木は、足元にブロックを積んで登って切ります。足場の土は、なければ近くの地面から借りて、終わったら埋め戻します
- 釣りは、待ち時間と釣れる魚の割合をまねたものです（本物の浮きは投げません。宝物やごみは釣れません）
- まだ誰も開けていない宝箱（遺跡など）の中身には触りません
- 拠点のまわり8マスでは資源を集めません。水や溶岩のそばは掘りません
- 1つのワールドに出せる仲間は5人まで

## 設定（`config/ainakama.json`）

初めて起動したときに作られます。

| 項目 | 初期値 | 内容 |
|---|---|---|
| provider | `ollama` | `ollama` / `anthropic` / `openai`（OpenAI互換のサービス） / `claude-cli`（下の説明を参照） |
| baseUrl | `http://localhost:11434` | 接続先のURL |
| model | `qwen3.5:4b` | 使うモデル。`claude-cli` のときは `haiku` `sonnet` など |
| claudeCommand | `claude` | `claude-cli` のときに動かすコマンド |
| apiKey | 空 | APIキー。環境変数 `AINAKAMA_API_KEY` でもよい（そちらが優先） |
| dailyCallLimit | 300 | 1日にAIを呼べる回数（全員の合計） |
| defaultPersonality | 明るくて元気… | 仲間の性格 |

APIキーはModの中には入っていません。配るときもキーを入れないでください。

### Claude のサブスクで動かす（`claude-cli`）

PCに Claude Code が入っていてログイン済みなら、`provider` を `claude-cli`、`model` を `haiku` にすると、APIキーなしで Claude に考えてもらえます。小さいAIより頼みをよく理解します。

- 呼ぶたびに `claude` コマンドを起動するので、返事まで5〜6秒かかります（Ollama は1〜2秒）
- サブスクの利用枠を使います（Claude Code と共通）。呼びすぎないよう `dailyCallLimit` はそのまま効きます
- ツールをすべて切って呼ぶので、AIがPCのファイルやコマンドに触ることはありません
- 環境変数 `ANTHROPIC_API_KEY` があっても、このコマンドには渡しません（APIの料金で動いてしまわないように）

AIを呼ぶたびに `logs/ainakama-usage.csv` に送った量・返ってきた量・時間を記録します。

## 開発

```
./gradlew build                       # ビルドと単体テスト
./gradlew runClient                   # 開発用のマイクラを起動
./gradlew runClientGameTest           # ゲームを起動して、集める・作る・建てる・焼く・畑・戦う・会話を自動で確かめる
./gradlew test -Dainakama.live=true --tests '*LiveModelEval*'   # 本物のAIに18個の依頼を送って返事を確かめる
```

- `core/`：Minecraft に依存しない部分（計画の読み取り、クラフトの手順、焼くレシピと燃料、設計図、決まった言い方、教わる言い方、技の帳面、文章づくり）
- `ai/`：AIの接続先、呼び出し回数の制限、使用量の記録
- `entity/` `task/` `world/` `command/`：ゲームの中の部分
